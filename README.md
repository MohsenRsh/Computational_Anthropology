# Computational Dissection of Individual Genomes for Ancestry Inference

My first time on a Linux system. I didn't know what grep was. I asked the professor how to write it and noted it down for the exam.

This is a bash command history from a Computational Anthropology course, preserved as it was. Raw, exploratory, full of typos and dead ends. No outputs, no graphs, those lived on the university system and are gone. What remains is the process.

The course covered population genetics methods for ancestry inference. Using Bash and Python scripts in a Linux environment, we applied LD pruning, PCA, ADMIXTURE, F-statistics, TreeMix, qpAdm and local ancestry inference with PCAdmix to study two admixed populations, the Hazara people and Puerto Ricans. I got 30 con lode.

One day, when I have my own genome sequenced, I want to come back to this and find out which populations I am connected to.

---

## What this project covers

Population genetics analysis using a merged 1000 Genomes and HGDP dataset (chromosome 1). Two admixed populations studied: Hazara (Central Asian, mixed East Asian and West Eurasian ancestry) and Puerto Rican (European, African, and Native American ancestry).

## Tools used

Bash, Python, PLINK, ADMIXTURE, EIGENSOFT (smartpca, convertf), SHAPEIT, TreeMix, qpAdm, qpGraph, PCAdmix
